## 🏗️ Architecture

### Clean Architecture × Vertical Slice — the real, current structure

*Legacy `Code/` (horizontal layers) is being migrated feature-by-feature into `Source/Features/` (vertical slices).
Battle, Fleet, Galaxy and Station domains have already moved — only shared config/logger primitives remain in `Code/Core/`.*

</div>

```mermaid
graph TD
    subgraph SF["📁 Source/Features/  —  ✅ ACTIVE, Vertical Slice"]
        direction TB
        subgraph Battle["🚀 Battle"]
            BD["Domain<br/><sub>BattleEntity · BattleResult</sub>"]
            BA["Application<br/><sub>IBattleService · CombatTickService</sub>"]
            BD --> BA
        end
        subgraph Fleet["🛰️ Fleet"]
            FD["Domain<br/><sub>FleetEntity · ShipEntity · ShipType</sub>"]
            FA["Application<br/><sub>IFleetService · CQRS commands</sub>"]
            FI["Infrastructure<br/><sub>FleetRepositorySO</sub>"]
            FP["Presentation<br/><sub>fleet UI screens</sub>"]
            FD --> FA --> FI --> FP
        end
        subgraph Galaxy["🌌 Galaxy"]
            GD["Domain<br/><sub>SectorEntity · GalaxyMapEntity</sub>"]
            GA["Application<br/><sub>IGalaxyService · GeneratorService</sub>"]
            GI["Infrastructure<br/><sub>GalaxyRepositorySO</sub>"]
            GP["Presentation<br/><sub>GalaxyMapRenderer · Presenter · Screen</sub>"]
            GD --> GA --> GI --> GP
        end
        subgraph Station["🏗️ Station"]
            SD["Domain<br/><sub>StationEntity · GridCell · ModuleEntity</sub>"]
            SA["Application<br/><sub>IStationRepository · IResourceService</sub>"]
            SI["Infrastructure<br/><sub>StationRepositorySO · ModuleSO</sub>"]
            SP["⏳ Presentation<br/><sub>NOT STARTED — Etap 3 Step 2</sub>"]
            SD --> SA --> SI -.-> SP
        end
        subgraph UI["🖥️ UI"]
            UC["Core<br/><sub>IScreen · ScreenBase · UIManager</sub>"]
            US["Screens<br/><sub>MainMenu · HUD · GalaxyMap</sub>"]
            UC --> US
        end
    end

    subgraph LG["📁 Code/  —  ⚠️ LEGACY, shrinking"]
        direction TB
        LC["Core<br/><sub>GameConfigSO · GELogger · ResourceWallet</sub>"]
        LP["Presentation<br/><sub>GameBootstrapper (DI root) · GameEntryPoint</sub>"]
        LE["Editor<br/><sub>SceneValidator · CodeHealthChecker</sub>"]
        LT["Tests<br/><sub>103 / 103 passing</sub>"]
    end

    subgraph DATA["📁 Data/  —  ScriptableObject instances"]
        DAT["Fleet · Galaxy · Station assets<br/><sub>GameConfig.asset — zero magic numbers</sub>"]
    end

    LP -.DI wires everything.-> Battle
    LP -.DI wires everything.-> Fleet
    LP -.DI wires everything.-> Galaxy
    LP -.DI wires everything.-> Station
    Fleet -.reads.-> DATA
    Galaxy -.reads.-> DATA
    Station -.reads.-> DATA

    style SF fill:#0D0D1F,stroke:#1D9E75,stroke-width:2px,color:#fff
    style LG fill:#0D0D1F,stroke:#D85A30,stroke-width:2px,color:#fff
    style DATA fill:#0D0D1F,stroke:#7F77DD,stroke-width:2px,color:#fff
    style Battle fill:#1a1a3e,stroke:#7F77DD,color:#fff
    style Fleet fill:#1a1a3e,stroke:#7F77DD,color:#fff
    style Galaxy fill:#1a1a3e,stroke:#7F77DD,color:#fff
    style Station fill:#1a1a3e,stroke:#7F77DD,color:#fff
    style UI fill:#1a1a3e,stroke:#7F77DD,color:#fff
    style SP fill:#3e2a1a,stroke:#D85A30,color:#fff
```
